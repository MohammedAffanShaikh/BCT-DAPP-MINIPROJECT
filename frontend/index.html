Decentralized Certificate Verification DApp

A tamper-proof, immutable academic credential verification system built on the Ethereum blockchain. Eliminates certificate forgery, enables instant public verification, and connects directly via MetaMask Web3 authentication.

Issue Certificate Verify Certificate

Tamper-Proof Ledger

Every certificate is recorded on the Ethereum blockchain using cryptographic SHA-256 hashing, preventing degree forgery and alterations.

Instant Public Verification

Recruiters, universities, and students can instantly query certificate authenticity in real-time with zero gas cost via read-only smart contract calls.

MetaMask Web3 Security

Smart contracts enforce `onlyAdmin` authorization, requiring authorized institute administrators to sign transactions through MetaMask.

Web3 Workflow

MetaMask ➔ Ethers.js ➔ Solidity Smart Contract ➔ Ethereum Ledger

01

1. Connect MetaMask

Admin connects MetaMask wallet and fills student credentials along with document SHA-256 hash.

02

2. Execute Transaction

Admin approves `issueCertificate()` transaction in MetaMask, mining immutable proof to the Ethereum blockchain.

03

3. Instant Verification

Anyone enters the Certificate ID to retrieve verified student records directly from the Ethereum smart contract.
