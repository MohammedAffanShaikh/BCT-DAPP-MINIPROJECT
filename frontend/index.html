Decentralized Certificate Verification DApp

A tamper-proof, immutable academic credential verification system built on the Ethereum blockchain. Eliminates certificate forgery, enables instant verification, and empowers universities and employers worldwide.

Issue Certificate Verify Certificate

Tamper-Proof Ledger

Every certificate is stored on the Ethereum blockchain using cryptographic hashing, preventing unauthorized alterations or fake degrees.

Instant Public Verification

Recruiters, universities, and students can instantly query certificate authenticity in real-time without middleman fees or delays.

Decentralized Ownership

Smart contracts ensure that only authorized educational institution wallets can mint and sign valid credentials.

How It Works

Three simple steps for issuing and verifying credentials

01

1. Admin Issuance

The authorized institute connects MetaMask and submits student details and document hash to the smart contract.

02

2. Ethereum Mining

The transaction is mined on Ethereum, storing immutable proof with a unique Certificate ID and transaction hash.

03

3. Universal Verification

Anyone enters the Certificate ID to retrieve authentic student records directly from the blockchain.
