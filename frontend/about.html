Project Abstract

Academic certificate fraud and document counterfeiting pose serious challenges to educational institutions, recruiters, and credential verification agencies worldwide. Traditional verification requires manual correspondence, third-party clearinghouses, and days of processing time.

This project introduces a Decentralized Certificate Verification DApp built on the Ethereum blockchain using Solidity 0.8.x smart contracts, MetaMask Web3 wallet authentication, Ethers.js, and static Netlify hosting. Educational institutions digitally mint student certificate data directly onto the immutable Ethereum blockchain. Anyone can instantly verify the validity of a certificate by providing its unique Certificate ID or SHA-256 document hash without relying on central server infrastructure.

Quick Viva Voce Q&A Guide

Q1: How does MetaMask act as the wallet and transaction authorization layer?

MetaMask injects `window.ethereum` into the browser. When the admin clicks "Issue Certificate", Ethers.js constructs the transaction payload and sends it to MetaMask. MetaMask prompts the admin to securely sign the transaction with their private key without revealing the key to the DApp.

Q2: Why does certificate verification not require sending a transaction or paying gas?

Verification queries call `view` functions in the Solidity contract (`getCertificate`). Read-only calls retrieve state from Ethereum RPC nodes without altering blockchain state, making verification 100% free and instantaneous for end users.

Q3: How is access control managed in the smart contract?

The contract maintains an `admin` state variable set to `msg.sender` upon deployment. The `issueCertificate` function uses the `onlyAdmin` modifier (`require(msg.sender == admin)`), preventing unauthorized users from issuing fake degrees.
